# Optimum-control-and-Non-Linear-System-Modelling
Modeled the nonlinear dynamics of an inverted pendulum using Newtonian and Lagrangian mechanics, linearized the system around
its equilibrium, and converted the equations into standard state-space representation.
Designed an optimal Linear Quadratic Regulator (LQR) for DC motor speed control by evaluating the infinite-horizon quadratic cost
functional.
Simulated controller step responses in MATLAB, tuning the Q and R weighting matrices to analyze the trade-offs between tracking
performance (speed priority) and control effort.
Plotted and analyzed system rise time and overshoot as functions of the varying Q22/R ratio using MATLAB's control systems
toolbox.
